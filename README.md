### Currently Building

**📱 Server on Phone: self-hosted portfolio**
My portfolio runs on an old Android phone set up to work like a real Linux server, with no managed hosting.
- **Reliability:** services start automatically on boot and restart after a crash, with a cron watchdog and log rotation
- **Secure exposure:** a Cloudflare Tunnel publishes the site from behind CGNAT without opening ports
- **Operations:** Git-based deployment and UptimeRobot monitoring with alerts

`Termux` · `runit` · `nginx` · `Cloudflare Tunnel` · `cron` · `logrotate` · `Git` · `UptimeRobot`

**🏗️ Home Lab: enterprise-style data & infra stack**
A small copy of the kind of platform I support at work, built from open-source tools and run in containers on WSL2.
- **Data flow:** NiFi ingests data, Airflow schedules the jobs as DAGs, and PostgreSQL stores the results
- **Observability:** Prometheus and Node Exporter collect metrics, and Grafana displays them on dashboards
- **Access:** containers run under Docker Compose, with remote access over SSH

`WSL2` · `Docker Compose` · `Apache NiFi` · `Airflow` · `PostgreSQL` · `Prometheus` · `Grafana`
